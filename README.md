# powerbi-mysql-sqlserver-dashboard
Projeto de Business Intelligence envolvendo migração de banco MySQL para SQL Server, tratamento dos dados em SQL e desenvolvimento de dashboards no Power BI.

# Dashboard de Business Intelligence

Projeto desenvolvido com o objetivo de transformar uma base operacional em um ambiente analítico utilizando SQL Server e Power BI.

Neste projeto foram realizadas todas as etapas de um processo de BI:

✔ Migração do banco MySQL

✔ Tratamento dos dados

✔ Modelagem

✔ Construção do Dashboard

✔ Geração de indicadores
